## 📁 How It Works — Troubleshooting Workflow

1. Confirm the installed Risk of Rain 2 build and Hallowed Concepts DLC status.
2. Start the game without mods and verify vanilla behavior.
3. Create a fresh r2modman profile rather than changing the only working one.
4. Update BepInExPack, required mod libraries and game-version-compatible mod packages from their original sources.
5. Enable mods in small groups to isolate which package triggers a startup or gameplay problem.
6. For multiplayer, compare the host and client profile manifests and align required gameplay-side packages.

## 🛠️ Troubleshooting Notes

Mod compatibility is version-specific. Do not assume a mod updated for an earlier DLC works with Hallowed Concepts.

If nothing changes, describe the exact symptom, current game version, Windows build, driver version and the last successful launch or working configuration when requesting official support.
